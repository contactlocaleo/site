# Kit d'icônes Localeo

Chaque application reprend le repère Localeo et utilise un glyphe métier distinctif :

- Animation : étincelle
- Administration : bouclier validé
- Control : cible de contrôle
- Coffret / Marketplace : cadeau
- Live : éclair
- Pro : mallette

## Fichiers

Les fichiers `*-icon.png` sont les masters PNG transparents (1254 × 1254 px).
Les fichiers `favicons/*-favicon-64.png` sont les favicons PNG (64 × 64 px).

## Intégration

```html
<link rel="icon" type="image/png" href="/localeo-application-favicon-64.png">
<link rel="apple-touch-icon" href="/localeo-application-icon.png">
```

Copier le master correspondant dans les assets de l'application pour l'affichage dans l'interface.
